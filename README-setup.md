# Можно себе 🌿

Прототип мобильного приложения для личного бюджета и накоплений. Можно установить на iPhone через Safari → Поделиться → На экран «Домой» после включения GitHub Pages.

## Возможности
- Доходы, расходы и переводы между счетами.
- Лимиты категорий, накопления, финансовые цели.
- Проверка доступности покупки и сценарии дохода.
- Резервное копирование JSON и экспорт операций CSV.

## Публикация
Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save. Адрес приложения: https://zubarevmarketplace.github.io/mozhno-sebe/

## Важно
Прототип, не банковский сервис. Никаких интеграций с банками, операций с деньгами или инвестиционных рекомендаций. Демонстрационные остатки вымышлены. Данные хранятся в localStorage браузера, без синхронизации и шифрования. Для защиты от потери данных регулярно экспортируйте JSON-копию. Не публикуйте личные финансовые записи и резервные копии в этом публичном репозитории.
